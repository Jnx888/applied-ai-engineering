# Security policy

## Scope

This policy covers the current `main` branch of all three reference projects: Object Evidence, Staffing Workbench, and Agent Capability Gateway. Older snapshots are not maintained separately. These are runnable engineering samples, not production services or security certifications.

## Report a vulnerability privately

Open this repository's [Security tab](https://github.com/Jnx888/applied-ai-engineering/security) and choose **Report a vulnerability**. Private vulnerability reporting is enabled. Please use that channel instead of a public issue for an exploitable security finding.

Include the affected project and commit, expected and observed behavior, likely impact, and a minimal reproducer using fictional fixtures. Keep reproduction local and include only the code or steps needed to demonstrate the problem. Do not upload real personal data, credentials, tokens, private documents, or production logs.

This policy does not authorize testing deployed services, third-party systems, or accounts belonging to other people. Reports are reviewed as maintainer availability permits; no response or remediation deadline is guaranteed. Non-security bugs can use ordinary repository issues.
